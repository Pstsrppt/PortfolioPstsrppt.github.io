# Portfolio: Pongsathorn Siriprompitak

เว็บพอร์ตโฟลิโอ 4 หน้า ทำด้วย HTML / CSS / JavaScript ล้วน (ไม่ต้อง build)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก: โลก 3D (Three.js) มีทัวร์ 60 วินาที ผู้ช่วย (?) และมินิเกมแบด |
| `projects.html` | หน้าผลงาน |
| `about.html` | หน้าเกี่ยวกับผม |
| `resume.html` | เรซูเม่หน้าเดียว กด "บันทึกเป็น PDF" ได้ |
| `data.js` | **ข้อมูลส่วนตัวทั้งหมด แก้ที่นี่ที่เดียว** ทุกหน้าดึงค่าจากไฟล์นี้ |
| `site.js` | สคริปต์ส่วนกลางของ 3 หน้าย่อย (เติมข้อมูล, คัดลอกอีเมล, แสงตามเมาส์) |
| `style.css` | สไตล์ส่วนกลางของ 3 หน้าย่อย |
| `images/` | ที่เก็บรูปโปรไฟล์และภาพหน้าจอ |

`index.html` มี CSS และสคริปต์โลก 3D อยู่ในไฟล์ตัวเอง ส่วนข้อมูลโปรเจกต์บนบอร์ดในโลก 3D อยู่ที่ `PROJECTS` ด้านบนของสคริปต์

## เปิดดูใน VS Code

1. เปิดโฟลเดอร์นี้ใน VS Code
2. ติดตั้งส่วนขยาย **Live Server**
3. คลิกขวาที่ `index.html` แล้วเลือก **Open with Live Server**

(ดับเบิลคลิกไฟล์ HTML เปิดตรงๆ ก็ได้ แต่ Live Server จะรีเฟรชให้อัตโนมัติเวลาแก้ไฟล์)

## Deploy ขึ้น GitHub Pages

1. สร้าง repository ชื่อ `Pstsrppt.github.io` บน GitHub (ต้องตรงกับชื่อบัญชี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (ไฟล์ `index.html` ต้องอยู่ชั้นนอกสุด)
3. ไปที่ Settings > Pages แล้วเลือก branch `main`
4. รอ 1–2 นาที แล้วเปิด `https://pstsrppt.github.io`
5. ทดสอบตาม Pre-submission check ของอาจารย์: เปิดใน Incognito, กดทุกเมนู, เปิดบนมือถือจริง, ดู Console, เช็กว่าไม่มีรหัสผ่านหรือ API key ในไฟล์
